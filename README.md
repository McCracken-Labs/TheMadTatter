# The Mad Tatter

Website for **The Mad Tatter** — Alice in Wonderland themed tattoo & body piercing shop in Shawnee, OK, owned by Isaac Bruno (Citizen Potawatomi Nation).

- Live site: https://mccracken-labs.github.io/TheMadTatter/
- Static site: open `index.html`.
- To add tattoo photos: drop images into `assets/tattoos/` and list them in the `TATTOOS` array in `index.html`.
